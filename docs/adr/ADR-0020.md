## Konteks
Vibe coding berisiko pada aplikasi keuangan.

## Keputusan
Kode zona merah dibuka hanya setelah dokumen direkonsiliasi, tes ditinjau, dan checklist gerbang di STATE terpenuhi.

## Alternatif dipertimbangkan
Coding langsung.

## Konsekuensi
Mutu terjaga; menambah disiplin dan waktu persiapan.
