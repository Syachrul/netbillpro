## Konteks
Gangguan gateway tidak boleh menggagalkan pencatatan pembayaran.

## Keputusan
Event ditulis ke outbox dalam transaksi; relay ke antrean; worker mengirim; pendengar idempoten.

## Alternatif dipertimbangkan
Kirim sinkron di request.

## Konsekuensi
Notifikasi andal dan dapat diulang.
