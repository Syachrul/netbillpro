## Konteks
Status per tagihan tidak dapat diturunkan dari saldo total.

## Keputusan
Tabel alokasi bertanda; satu fungsi reallocate dipanggil di akhir tiap operasi; tervalidasi model referensi (ADR-19).

## Alternatif dipertimbangkan
Hitung status dari saldo saja.

## Konsekuensi
Logika alokasi satu tempat. Skema perlu E-3 (invoice_id nullable + refund_ledger_id).
