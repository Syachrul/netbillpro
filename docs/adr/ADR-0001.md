# ADR-0001: Modular monolith

| Atribut | Isi |
| :--- | :--- |
| Status | **Diterima** |
| Dasar | Struktur repo Tahap B (api, worker, web, shared) |
| Implementasi | Sebagian: batas modul belum ditegakkan lint (verifikasi di C3) |
| Tanggal usulan | 2026-11-13 (ditinjau 2026-11-15) |
| Pemutus | Owner / Eng Lead |
| Rujukan | TDD §2.2/§25.13 (ADR-01 bila ada), `docs/decisions.log` |

## Konteks
Tim kecil, skala ≤ 2.000 pelanggan saat go-live (desain hingga 5.000), transaksi ACID lintas modul.

## Keputusan
Satu deployable dengan modul domain terpisah; batas modul ditegakkan lint; modul lain hanya lewat index.ts.

## Alternatif dipertimbangkan
Microservices.

## Konsekuensi
Operasi sederhana; ekstraksi layanan dimungkinkan kelak. Risiko coupling bila lint batas modul tidak aktif.
