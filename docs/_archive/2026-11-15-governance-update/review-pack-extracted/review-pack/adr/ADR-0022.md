# ADR-0022: ORM: Prisma untuk CRUD + SQL mentah untuk ledger (T2)

| Atribut | Isi |
| :--- | :--- |
| Status | **Diterima** |

| Implementasi | Sebagian: skema ada; ledger raw SQL belum (C3) |
| Tanggal usulan | 2026-11-13 (ditinjau 2026-11-15) |
| Pemutus | Owner / Eng Lead |
| Rujukan | TDD §2.2/§25.13 (ADR-22 bila ada), `docs/decisions.log` |

## Konteks
Ledger butuh FOR UPDATE, urutan kunci, dan kontrol penuh atas SQL; CRUD butuh produktivitas.

## Keputusan
Tulis ke ledger_entries/payment_allocations hanya lewat $queryRaw/$executeRaw di transaksi interaktif modul ledger. Klien Prisma tidak menulis tabel ledger. Objek DB kustom (trigger, CHECK, unique parsial) hidup di migrasi SQL. Dilarang `prisma db push`. Tambah gerbang CI cek drift skema.

## Alternatif dipertimbangkan
Kysely/Drizzle, Prisma penuh.

## Konsekuensi
Dua gaya akses data: perlu aturan lint/CI. Prisma mungkin tidak mengelola objek DB kustom dengan baik: uji `prisma migrate dev` agar tidak menghasilkan DROP untuk objek kustom.
