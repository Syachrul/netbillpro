# ADR-0008: PDF dengan pustaka dokumen ringan (pdfmake)

| Atribut | Isi |
| :--- | :--- |
| Status | **Diusulkan** |
| Dasar | Menunggu persetujuan sebelum S5. Diperjelas dari TDD (pdfmake atau react-pdf) menjadi pdfmake |
| Implementasi | Belum |
| Tanggal usulan | 2026-11-13 (ditinjau 2026-11-15) |
| Pemutus | Owner / Eng Lead |
| Rujukan | TDD §2.2/§25.13 (ADR-08 bila ada), `docs/decisions.log` |

## Konteks
Target p95 < 1,5 detik dan memori kecil.

## Keputusan
pdfmake (alternatif: @react-pdf/renderer bila pdfmake tidak memadai).

## Alternatif dipertimbangkan
Headless Chromium.

## Konsekuensi
Lebih ringan; kontrol tata letak terbatas kemampuan pustaka.
